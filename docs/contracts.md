# Contract Versioning

JSON Schema files under contracts/schemas are the canonical wire-contract source.

The checked-in contracts/src/generated-schemas.ts artifact is regenerated by:
pnpm generate:schemas

Version fields are separate:
- apiVersion: compatibility level of the public interface
- schemaVersion: wire/data shape version
- version: implementation/module/provider/tool version

A breaking wire change increments schemaVersion. A breaking public API change increments apiVersion. Implementation-only changes increment version.

Foundation currently uses API 1 and Schema 1. Compatibility is version-gated at boundaries rather than hidden inside Core.

Runtime validation is provided by SchemaValidator. The Foundation validator intentionally supports the subset required by the current contracts and tool parameter schemas; a full JSON Schema engine such as Ajv can be introduced later without changing the Broker contract.
